# User Profile & Admin Management System

A role-based User Profile and Admin Management System built using React and Redux Toolkit.

## Features

- User Registration
- User Login
- Logout
- Protected Routes
- Role-Based Access Control
- Profile Management
- Edit Profile
- Change Password
- Admin Dashboard
- Admin User Management

## Tech Stack

- React
- Redux Toolkit
- React Redux
- React Router
- Axios
- JSON Server

## Installation

Clone the repository:

git clone <repository-url>

Install dependencies:

npm install

Start the React application:

npm run dev

Start JSON Server:

npm run server
